# 数据目录与真实会话修复：交付及归档说明

## 合入的产品改动

- `AppCompatibility.ResolveDataPath` 固定使用 `DiskPilot-X`，不根据旧品牌目录存在与否回退。
- 会话、设置、分析上下文、技能清单与规则、白名单复制及更新元数据保存时使用可读中文 JSON。
- 技能摘要继续使用固定规范编码，与磁盘展示格式分离；DPAPI 凭据加密及会话授权校验保持不变。
- 不包含 `AppDataMigration`、启动自动迁移或迁移专用授权入口。标准 JSON 解析未增加旧格式分支，专项旧转义读取测试片段已删除。

## 用户真实数据修复及纠错

此前工具看到的 46 份会话实际属于 Codex 的 AppData 重定向缓存，不代表用户资源管理器中的真实目录；相关真实数据完成结论撤回。

最终仅通过用户资源管理器进程返回的原生 `Folder.Application.NameSpace` / `CopyHere` 通道处理指定真实会话及其 `metadata`。真实原件为 610068 字节，修复后为 446026 字节；外层和 17 个嵌套 JSON 业务字段已规范化，Unicode 转义计数为 0。业务值、普通文本及其他字段保持一致，元数据只更新正文长度绑定。当前正式 Core 可读取，原有效授权保持有效。真实目录仍为 1 份 JSON 和 1 份 metadata；旧品牌用户目录未处理。

正式原生读回结果 SHA-256：`82AE4E1183FB6F7184DF2746469177CE2877FDCEC1B9AA8E887CA7AEB37DF978`。

## 验证与限制

- 分支完整回归：Core 733 项通过；App 580 项通过、1 项既有彩色旗帜字体测试跳过。
- 此前文件夹发布包已分别验证实际 `asInvoker` 和 `requireAdministrator` 清单，并验证发布环境源码编译、授权只读执行、失败诊断及非提权 UI。
