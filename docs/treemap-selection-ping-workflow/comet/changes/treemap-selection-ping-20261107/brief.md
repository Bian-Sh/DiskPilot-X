# 验收示例
- 普通点击单选；Ctrl 点击在首次单选基础上增减多选；右键已选项保留集合，右键未选项切换目标；拖动不能误选，选择状态和数量可见。
- 右键支持将单项或多项加入推荐清理；重复路径和父子重叠不重复累计；保留旧建议和旧勾选，手动条目标明来源，添加不执行删除。Treemap 右键不再显示定位（Ping）调试按钮，推荐列表与对话引用的定位功能保持。
- 仅添加当前扫描内真实、未删除、非聚合 IOEntity；不伪造 AI 风险评估或绕过原清理确认、安全保护和来源校验。
- AI 忙碌时右键删除点击后显示约 5 秒 toast，说明正在查看文件、避免文件变化影响判断及回复结束后可重试；不静默返回、不弹阻断对话框，也不执行删除。
- Ping 存在的文件或目录用 #FEA400 橙色独立描边；在最终视野动画和布局更新完成后，前约 80 毫秒快速压实亮起边框，再由边框向外轻微扩散光晕并衰减，总长约 800 毫秒。不得周期闪烁、抖动视野或改变真实 cell 面积；结束释放提示状态，不遗留常驻橙框。后续 Ping、用户操作或控件卸载取消旧提示；不存在或不可定位时明确提示，普通白色选择与 Ping 高亮区分。地图边缘允许橙框与光晕自然裁剪，不强求完整显示。
- Ping 太小则放大、太大则缩小，目标尽可能进入可视区域；恢复原地图边界钳制，不为提示留白而越过地图边界。已有合适位置不强制居中；层级外目标切换到可展示层级。
- Ping 的平移、缩放和层级改变保持缓动连续视野追踪；普通定位开始前使用目标倍率的稳定布局和原地图钳制计算真实落点，避免到达后再重布局并启动第二段拉回。后台准备期间保留当前画面，布局接管保持视觉连续；目标接近方向不因布局提交反向回摆。动画可被手动操作或后续 Ping 打断，异步布局完成后仍指向正确实体，不回弹到过期目标。
- 全部相关测试通过；在非提权完整文件夹发布环境用应用窗口 UI 验收选择、推荐、toast、平滑定位和源码规则编译/安全执行。
- 主仓库 outputs 下生成可读时间命名的测试包和用户交付包；实际 EXE 清单分别 asInvoker 与 requireAdministrator，保留运行时 DLL、Core DLL 和 skills，不生成 ZIP。
