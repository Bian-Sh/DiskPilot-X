# Treemap 选择、手动推荐与平滑 Ping
## 选择和右键
普通单击建立唯一选择；Ctrl 点击在现有单选基础上增减集合。右键命中集合内项目保留集合，命中集合外项目转为单选。左键拖动仍平移，不误选。多项具有可见描边和数量反馈。
Treemap 右键不显示定位（Ping）调试入口。推荐列表、对话引用和宿主 focus_path 定位功能保留。
## 手动推荐
右键新增加入推荐清理动作，批量使用去重后的真实 IOEntity。按 Windows 路径不区分大小写去重，父目录覆盖子项时不重复累计。保留既有建议及勾选，新增建议明确为手动添加、默认不勾选，不伪装 AI 已评估风险。聚合块、删除条目及过期扫描条目不可提交。原清理授权、安全保护和确认保持不变。
## 忙碌反馈
AI 正在查看文件时，用户点击删除收到非模态短暂 toast：AI 正在查看文件，暂时不能删除，避免文件变化影响判断。等本轮回复结束后再试。该状态绝不执行删除；扫描或清理忙碌的限制同样不得静默失败。
## 平滑 Ping
沿用宿主 focus_path 定位能力，统一推荐定位和引用定位能复用的链路。先在当前地图寻找实体，只有当前层级无法展示时才调整层级。独立橙色 #FEA400 描边不冒充普通白色选择。根据屏幕 cell 大小调整缩放，采用最少平移使目标尽可能进入可视区域，不强制居中。恢复原地图边界钳制，不为提示额外越界留白；边缘允许橙框和光晕自然裁剪。
平移、缩放通过短时缓动连续追踪，层级切换也提供视觉连续过渡，不瞬间硬切。动画绑定目标实体与当前布局，新 Ping 或用户操作使旧动画失效。过小/过大和细长目标在视口预算内尽可能清晰，不为了最小尺寸把另一边无限放大。
普通定位启动前先稳定目标倍率的布局，再按原地图边界计算落点。不得先用旧布局 tween 到临时落点、提交 LOD 后突然改变实体位置，再启动第二段拉回。后台准备仍显示旧画面，布局接管与镜头追踪保持视觉连续；不因布局提交产生目标反向回摆或停稳后再移动。
橙框只在最终视野和布局停稳后出现一次强烈的撞击扩散提示，类似 Unity 编辑器 Ping 或雨滴落地的冲击感：前约 80 毫秒边框快速压实亮起，随后光晕向外轻微扩散并连续衰减，总长约 800 毫秒。不使用周期闪烁，不抖动地图或缩放真实 cell。布局重绑不能提前消耗提示时间；新 Ping 重启完整提示，用户操作或卸载取消旧提示，结束后不影响普通选择。边缘裁剪是地图边界约束的正常代价，不强制完整显示提示。
## 发布与证据
自包含、不裁剪、不单文件；统一输出到主仓库 outputs。非提权测试包验证 UI 和发布环境源码规则，用户交付包验证真实提权清单及文件完整性。未经提权实际 UI 验证不声称其已验收。
