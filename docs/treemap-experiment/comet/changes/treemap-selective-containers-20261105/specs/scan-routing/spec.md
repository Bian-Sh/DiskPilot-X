# 可解释自适应扫描路线

## 决策与执行分离
系统依据实际卷能力、同范围USN及有效完整卷缓存、近期成功阶段耗时决定路线；管理员身份不保证MFT。每次保留策略版本、原因码、输入证据、估算区间/未知与实际尝试。子目录不得按GB或目录名字猜规模。

## 有界渐进遍历
未知子目录先实际遍历，约500ms或2048条目为协作式检查点，枚举不另起第二遍；小目录完成就完成，证据不足继续。仅当保守MFT剩余成本不超过遍历剩余成本75%、且保守节省至少2秒时主动切换；一次扫描最多一次主动切换。MFT失败复用原枚举继续；取消停止，不回退或标成功。

## 有效缓存与最小化统计
同路径USN校验有效优先；完整卷缓存仅在卷身份/覆盖/排除规则/日志水位均有效时投影目标，变化或校验失败不得返回旧数据。完整索引仅会话有界保留，不额外持久化文件名；历史统计仅本地哈希标识、条目量和阶段耗时，不上传。失败取消不记录成功样本，不自动提权或创建USN。

## 用户反馈
复用扫描遮罩原因行和控制台/摘要，显示实际路线与能力理由、预测来源/可信度、切换或失败阶段及错误码。无可靠证据时明确无法估算，数值预测不能冒充实测。整卷索引处理量与目标文件数量分开。UI和无头工具共享执行记录，不新增推荐列表顶部状态条。

## 验证边界
覆盖能力/路径/历史成本、探测复用、范围排除、缓存失效、失败回退/取消，保留树图性能交互、清理安全回归。实际双包清单与发布源码规则验收；无真实提权MFT证据不宣称真机已验。
