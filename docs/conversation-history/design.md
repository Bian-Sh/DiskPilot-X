# 历史对话设计

沿用现有 WPF MVVM 与 TinyHarness 会话，不引入存储依赖。参考 Loom-X 的会话标识、标题提取、最近更新排序、中断恢复与安全消息投影；本项目使用每会话 JSON 快照，同时保存模型历史与 UI 消息分段，以便准确恢复本项目展示。

新增按钮为轻量的 40×26 复合操作，左侧 28 为主要热区，右侧 12 打开历史。加号与箭头均采用居中的几何路径，消除字体基线造成的视觉偏下；加号轮廓为 10×10，箭头为 6×4；两者使用完全不透明的主题文字主色，描边分别为 1.4 和 1.2，独立保持清晰。常态使用主题表面背景并保留无外框样式，分割线宽 1，上下各留 2，实际高 22；采用随背景明暗派生的主题浅边框色，以 0.55 不透明度叠加在按钮底色上，仅比底色略明显，存在感低于图标；分割线不参与命中测试，悬停时显示主题高亮；按钮保留悬停提示。发送与停止按钮共用直径 32 的正圆外形，沿用主题配色与悬停、按下、禁用状态。历史项显示首条用户消息压缩后的标题与更新时间，当前项有标识，空列表显示提示。历史弹窗保留独立 Popup，取消固定水平偏移，从按钮左边缘下方自然展开，允许越过聊天面板和应用窗口边界。复合按钮的高亮仅保留整体外侧圆角：左侧为 8,0,0,8，右侧为 0,8,8,0，拼接边缘保持直角；其他普通按钮继续使用原来的圆角。

非空会话在发送、完整消息检查点、结束、新建和切换前保存；写入临时文件后原子替换。历史仅存于本机应用数据目录，不保存模型凭据、旧确认卡或磁盘对象引用。恢复时应用当前系统提示并修复悬空工具调用，运行中残留状态归为取消；白名单变化继续遵循现有隔离策略，旧模型上下文不进入新请求。

运行期间禁用新建和加载。读写失败给出可见提示，加载损坏文件保留当前视图。启动时打开空白会话并加载历史索引，不自动恢复或执行工具。

验证覆盖重启续聊、取消、文件损坏、排序、工具展示和白名单隔离；以目标应用窗口检查复合按钮与历史弹层，并发布到 outputs 时间目录。
