# 本地化与聊天呈现

# 目标
参考 Loom-X 完善 DiskPilot-X 的运行时本地化与 skill 动态 UI 语言状态响应，并修复聊天 Markdown 行内代码、列表和 emoji 呈现。
# 范围
统一语言状态、自动语言回退、线程文化和切换通知；提供 skill 只读语言快照与变更订阅；动态 UI 根据语言资源更新文案且保留输入和数据；修正聊天代码基线、列表间距和彩色 emoji；补充资源、接口文档、测试和文件夹发布验收。

# 非目标
不改写历史聊天消息，不自动运行破坏性 skill，不合并或提交已有会话改动，不清理其他会话文件。
# 验收示例
1. 简中、繁中、英文与自动语言读取及切换一致，后台线程能读取稳定状态；无效语言不使应用崩溃。
2. skill 可查询当前语言并订阅真实变化；旧 skill 兼容；关闭窗口解除订阅。
3. 动态 UI 首次按当前语言呈现，切换后更新文字且保留表单和结果，不自动运行任务。
4. 截图对应列表中英文不被拉伸，行内代码基线正常，长路径可阅读，emoji 彩色且保留完整组合字符。
5. 相关回归及全量测试记录真实结果，使用非提权测试包完成应用窗口截图验收。
6. 两个自包含文件夹发布包保留 DLL 和 skills，实际清单分别为 asInvoker 和 requireAdministrator；发布环境验证源码编译和经授权的只读执行以及错误诊断。
