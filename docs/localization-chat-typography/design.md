# 本地化与聊天呈现设计及实施计划

目标：在现有 WPF / Core 边界内移植 Loom-X 的行为，不照搬 Avalonia 控件。

## 契约
- 统一语言状态包含用户选择（含 auto）、有效文化与可用资源语言；无效设置安全回退，跨线程读取稳定。
- skill 桥暴露只读状态和变更订阅；不授予修改应用语言权限。默认接口实现保持旧桥兼容。
- skill 自有 i18n/<culture>.json 文案按英文默认、父文化及精确文化回退；动态 UI 可声明本地化键。
- 语言切换仅更新显示属性，保留控件实例、用户输入、选中项、任务结果；真正关闭时解除订阅。
- Markdown 统一在共享转换器修复左对齐、列表缩进、行内代码基线、长路径换行；emoji 以完整字符簇处理，并验证 WPF 彩色输出。

## 实施顺序
- [x] 本地化：先写语言状态和桥契约回归测试并观察失败，再实现状态、资源回退、宿主注入；补动态 UI 测试后实现响应和文档。
- [x] 聊天：独立工作单元修改共享转换器及新增辅助文件和测试；复现代码上浮、混排拉伸、emoji 后修复。不修改主任务的语言文件。
