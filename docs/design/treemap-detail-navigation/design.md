# Treemap 内容与导航修复

## 用户目标
非空目录即使折叠或内容极细也有颜色；光晕跟随指针；左键拖动平移且保留单击、Ctrl 多选、标题双击；按 Disktree 的目录内容适配阈值实现滚轮进入与退出；中键单击居中所在目录，移除中键平移。标题、字号、描边保持屏幕固定规格；选中框纯白。

## 根因与实现
原布局硬性限制深度、每目录仅保留 20 项、低于 14 DIP 丢弃。目录内容使用稳定文件类型颜色作为占用底图，标题带独立灰底；最小填充下降到像素级，长列表尾部聚合并保留真实父目录作为交互对象，不创建虚假文件。取消随 zoom 限制深度，保留面积与数量预算。
左键在释放时区分点击与拖动，超过阈值取消点击；丢失捕获取消拖动。滚轮参考 D:/AppData/Github/disktree/crates/disktree-app/src/state.rs 的 zoom_at/zoom_target：缩放达到指针下非空目录内容适配视口的阈值后进入，1x 继续缩小退出；只在当前扫描树内返回。导航时同步根与 zoom，并保存滚轮进入前的视口用于恢复。用户补充：中键仅改变平移，倍率、cell尺寸、根目录均不变，不开始拖动。为使边缘小目录也精确居中，中键定位时允许地图边缘进入视口；缩回全局或按0复位，非中键定位状态下，普通平移约束在地图内；中键定位状态保留有限定位边界，复位后恢复默认。

## 验收
1. 折叠目录内容有色，灰色标题不染色；空目录不进入布局；长尾大小不丢失。
2. 同 cell 内移动与缩放平移后，光晕中心跟随指针，目录标题不发光。
3. 左键点击、多选、双击保持；拖动只平移不触发点击。
4. 对准目录连续滚轮进入，反向到 1x 退出，恢复父级视口；最外层不能继续缩小或露黑边。
5. 中键选择文件或目录都居中对应目录，移动鼠标不产生中键平移。
6. 全量测试、发布包启动与窗口内交互验收，按北京时间新建 outputs 发布包。
