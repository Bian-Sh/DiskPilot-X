# Treemap 内容、导航与视觉

## 当前交互

非空目录即使折叠或内容极细也显示占用色；空目录不进入布局；超过 128 项的长尾聚合保留真实大小与父目录身份。标题和字号保持屏幕固定规格，选中与多选外框使用纯白，光晕跟随鼠标。
左键在释放时区分点击和拖动；保留单击、Ctrl 多选、目录标题双击。
中键置中功能已删除，没有中键缩放、置中、拖动或放宽边界模式。所有普通平移均约束在地图内，1x 时 pan 恒为零。

## 滚轮 Snap

参考本地 Disktree 的 zoom_at/zoom_target：达到指针下非空目录内容适配视口的阈值后进入，缩到 1x 再向外滚时按真实父目录退出；不越过扫描根，并在返回保存的祖先时恢复原视口。
换层成功后保持完整新层视图至少 450ms，同时消费连续滚轮余量；需要最近 140ms 无滚轮输入后，下一次输入才恢复缩放。进入与退出都应用此约束，防止标题被连续输入直接滚过。
普通缩放没有节流，重置视图或显式导航会清除滞留状态。使用可注入 TimeProvider 验证时序，不在生产代码阻塞或睡眠。

## 视觉

参考 D:/AppData/Github/disktree/crates/disktree-app/src/palette.rs 的统一低饱和与相近明度原则，并结合用户提供的平缓色彩过渡示例。源码蓝灰、工具与运行库灰绿、媒体淡紫、缓存沙色、归档灰青、文档中性灰蓝；移除高饱和红与玫红。
大于 32×24 DIP 的文件块增加上下各约 3.5% 的同色系轻渐变；小块保持纯色，避免细节被阴影吞掉或增加大量 shader 开销。文件边框从加深 65% 降为 14%，标题仍为中性深灰、无文字阴影。
