# 聊天气泡悬停、复制与用量

2026-10-26

## 交互约定

消息根容器使用透明背景接收命中，范围包含正文、操作栏上方间隙和操作栏。操作栏保持布局占位，悬停消息或键盘焦点处于消息内时显示，鼠标离开后隐藏。用户操作栏右对齐，AI操作栏左对齐。AI底部仅展示已记录的完成时间和复制按钮；尚未完成时不显示时间，不将创建时间或执行时长放入底部。用户消息仍展示发送时间。默认在消息下方显示紧凑用量胶囊，例如 9.8K tokens；悬停胶囊后在上方显示两列明细卡片，数值右对齐。胶囊独立于时间/复制操作栏，保持可发现性。没有准确的模型生成耗时，不展示 tokens/s。

## 用量约定

复用现有模型完成事件及助手完成快照，增加可选 ModelTokenUsage。支持 OpenAI Chat Completions 独立用量帧、Responses 完成帧及完整 JSON、Anthropic 起始与增量用量。Anthropic输出是累计值，覆盖更新；其总量包含未缓存输入、缓存读取、缓存写入及输出。推理token是输出的子集，不额外计入总量。

同一AI气泡跨工具步骤累计已报告用量，按模型消息ID防止重复完成快照计数。字段未提供则不显示，明确报告零则显示零；没有usage的旧历史不伪造统计。悬停卡片标记“已报告用量”，避免将不完整上报当作整轮完整消耗。历史快照用可选字段保存并兼容旧记录。

## 验证

回归先证实旧实现缺少用量请求和透明命中背景。覆盖三种协议、完整JSON、独立尾帧、缺失/非法值、累计输出、多步累加、去重、历史恢复和真实AgentLoop数据传递。真实WPF布局检查用户与AI操作栏对齐，检查隐藏操作栏及上方间隙仍命中消息根容器，原有滚动行为保持通过。发布包使用独立历史样例验收，样例数字仅用于界面检查。
