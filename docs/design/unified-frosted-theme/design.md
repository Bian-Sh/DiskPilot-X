# 统一磨砂主题

主题保留深色、浅色预设和背景色选择。磨砂只保留一个开关与一个浓度滑杆，不暴露材质类型和模糊半径。0% 为最通透档，100% 不透明，默认 60%。磨砂开关、浓度与配色独立；更换配色、保存和重新打开设置都保留用户选择。

失焦后通透感降低属于正常系统行为，继续交由 DWM 管理。失焦仅影响视觉呈现，不改变保存的磨砂开关、配色和浓度。验收须区分激活与失焦状态，不能仅凭失焦灰底判断磨砂失效，也不应为追求失焦通透而更换原生材质路径。

材质使用系统 DWM 的 Acrylic：DWMWA_SYSTEMBACKDROP_TYPE=38，开启值为 3，关闭值为 1。移除上一轮的 AccentPolicy/SetWindowCompositionAttribute 路径。材质创建成功后复用，颜色和滑杆只更新应用背景画刷；关闭后清除成功状态，再开启重新申请。系统不支持或调用失败时使用实色回退。

GlassOpacity 保存用户选择的 0–1 浓度值，与界面百分比同向换算。实际背景叠色按 0.08+0.92×GlassOpacity 渲染：最通透档保留少量主题色，避免宿主完全透明后颜色只在不透明设置浮窗中可见；100% 的实际 Alpha 为 255。配置缺省值 0.6，旧配置继续读取，非法值回退默认。旧的材质类型与模糊半径字段忽略。

背景颜色选择必须沿颜色选择器→SettingsViewModel→ThemeManager→真实 MainWindow.RootGrid 同步，不能只验证拾色器和设置卡片。设置浮窗使用不透明底色，保留透明交互遮罩和柔和阴影。文字使用独立画刷，不调整整个窗口的 Opacity。

参考 tubatools 的原生材质、明暗同步和实色回退原则；保留现有 WPF/DWM 集成，不引入 WinUI 依赖。

验收包括：颜色选择器输入后真实宿主像素随颜色变化；最通透档仍可见主题色；DWM 开启、关闭、再开启的读回为 3/1/3；实际滑杆 0/25/50/75/100 单调增加遮色，关闭后再开保留浓度；设置面板 Alpha 保持 255；显示窗口中可见磨砂与实色的对照；发布经过宿主回归验证的 Windows x64 自包含包。
