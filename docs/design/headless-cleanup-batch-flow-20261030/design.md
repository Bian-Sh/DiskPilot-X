# 无头扫描、对话入口与清理发布设计

## 数据与生命周期

- ScanSession/FileEntry 完整树只在进程内；ScanSnapshotCache 以扫描Id区分版本，根路径不是身份。
- ScanSnapshotReference 仅保存Id、缓存代次、范围、时间与统计；可用/失效/忙碌为当前运行态，不持久化为许可。
- 默认缓存最多12份、总条目权重500万；按最近访问回收未受保护结果。展示、分析、清单使用具名保护，预算不足明确失败。
- 当前会话的分析批次可累积，切换会话或清空清单失效。查看缓存可跨同进程会话切换，但不恢复模型上下文和旧清理授权。

## 用户入口

无头扫描后对话留卡片，不替换Treemap。点击命中快照只切换Treemap、目录树与扫描事实；重启、回收、路径或当前安全限制均重新计算状态。历史保留入口，重扫必须显式点击，并产生新Id/时间。任务繁忙时不抢占工作区。

## 发布事务

默认追加、按路径去重并保持选择。空结果不清空原清单。批次与普通发布共用提交边界；覆盖在当前调用内只确认一次，绑定提交前清单与相关安全策略修订；异步确认后重新检查。许可不保存到字段，返回、取消或异常都会结束本次许可，不跨请求续签。相关策略修订单调推进，显示语言等无关设置不误伤。最终删除继续使用原有最终复核和新确认。

## 存储与失败

.summary 只服务展示，按源文件长度/时间验证；缺失或损坏局部重建。.metadata 仍独立服务授权核验。内容指纹区分真实消息变化和浏览/标题更新，后者不推进历史排序。

失败/取消原因成为可持久化的可见段落。工具参数按对象键排序，第三次同错误停止本轮；相同成功查询不算新进展。保留既有有限重试与流事件后不透明重放边界。

## Unity

移除第一个参数ui.xaml，skill中ask_user收参数。默认只回Library路径及少量统计，完整视图留本地。inspect模式按需读取项目内容目录时间与可识别的本地Hub记录，未知不猜，512字符Detail预算内保持完整结构。近期活动/Hub不在册都不等于可以删除。

## 验证边界

只读夹具、独立验收设置和日志目录；不读写真实用户会话。测试包asInvoker、用户包requireAdministrator，均文件夹自包含。实际EXE资源清单、动态源码编译执行、三范围发布和应用窗口分别验收，未执行者不得标通过。

## 第二轮修复边界

增量变更采用写时分离，先复制树和FRN索引，取消/失败恢复旧状态；无变化刷新也不改写旧会话时间。推荐项仅由宿主记录SourceScanId并按精确版本导航，不由路径/MRU猜测。该字段不序列化到模型候选，也不是执行许可。

重试的等待与开始状态以专用事件投影为可保存的过程段落，不混入模型最终正文。普通发布保留最初提交与拒绝计数；确定性验证拒绝与执行故障分开，不覆盖旧清单，也不把受限结论改成无推荐。

显式错误证据Id禁止降级到主扫描。规则、偏好、隐私、扫描策略、会话批次和清单变化分别给稳定类别与下一步，不再用笼统的“确认期间变化”替代可核实原因。
