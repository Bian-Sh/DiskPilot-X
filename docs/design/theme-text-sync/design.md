# 文本主题同步修复

用户要求面包屑和其他文字在浅色、深色、自定义主题之间即时同步。此次只修复颜色资源与相关文字容器，原生磨砂、透明度计算、失焦行为保持原实现。

根因：直接写共享 SolidColorBrush.Color 会移除原有绑定，后续资源被样式冻结。主题更新替换了资源里的画刷，已创建的面包屑、弹窗和 Markdown 仍持有旧浅色引用。菜单自定义样式未继承主题 MenuItem，提示与日志另有固定色。

共享画刷使用显式颜色源 ThemeColor.Value 的 OneWay 绑定。ThemeColor 实现 INotifyPropertyChanged；后续只更新颜色源，不改写画刷 Color 本地值。绑定令画刷保持不可冻结，旧引用也可接收更新。颜色资源继续保留，新增 VP.BackgroundTint 仅承载原来已计算的宿主背景 Alpha，VP.Background 仍是原始背景色；VP.OverlayBrush 也由统一颜色更新驱动。

面包屑菜单继承已有主题 MenuItem，并让数据模板文字跟随容器前景。树图提示使用主题底色、文字和边框；访问拒绝与白名单错误使用危险语义色。日志正文与时间使用主文字和三级文字，日志级别与错误使用主题语义色。控制台和更新日志容器随主题变化，避免浅色文字落在固定深底；复制图标、光标及树列表百分比也使用对应主题资源。旧设置对话框同步常规文字与控件配色。彩色徽标、强调按钮等保持白字对比。

验证创建后不重建的实际控件，在浅色→深色→自定义文字色切换时同步：面包屑名称和箭头、子目录菜单、提示、确认弹窗、Markdown、日志、旧设置提示和控制台容器。实际文字回归使用独立 PowerShell 7.6/.NET 10 进程及隔离配置；另运行原宿主回归，核对背景 Alpha、宿主像素与 DWM 3/1/3 未变。完成后后台 GUI 截图确认面包屑文字，并重新发布自包含包。

独立语义文字色资源包括 VP.AccentText、VP.AccentHoverText、VP.SuccessText、VP.WarningText、VP.DangerText 及对应 Brush。基于实色面板底色调整文字明度，最低对比度为 4.5:1；背景和边框继续使用原始语义色。链接、日志标签、警告错误文字使用文字变体。树展开箭头默认使用主文字色；百分比填充保持 Accent，降低为 35% 以保证主文字色在条内也清晰，该参数不涉及磨砂。
