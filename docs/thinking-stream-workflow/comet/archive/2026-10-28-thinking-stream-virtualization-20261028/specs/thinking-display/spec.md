# 思考展示
思考是可回看的完整数据，不是必须一直展开的聊天正文。默认折叠时，标题旁显示有长度上限的最新增量预览，并以轻量滚动表达模型仍在推送；展开后只显示下方全文。
正文必须在有限视口中回收复用可见片段，不能将整段文本放在单个巨大控件中；原始思考不截断、不改变持久化数据。用户上翻阅读优先于尾部跟随，只有重新到达底部才恢复跟随。
高频事件必须合并 UI 刷新而不等待 UI 完成排版，语义事件与结束冲刷保持顺序。所有改变均限于渲染与事件调度，不修改模型请求内容。
# 验证
覆盖默认折叠、标题与正文互斥、十万字符以上及无换行输入、可见容器数量、滚动阅读位置、生命周期、错误和结束有序落盘；真实发布包必须保留运行时源码编译依赖及双清单。

# 用户确认的空闲超时与扫描取消
模型等待采用连续5分钟未收到新消息的空闲时限，收到正文、思考或工具参数等新流数据时刷新。持续推送不受总时长限制。新建和历史恢复会话同样生效，用户停止可随时取消。计时只约束模型等待，不累计磁盘扫描和用户本地消费/展示耗时。
磁盘扫描、规则只读发现和扫描分析不设置固定总超时，取消令牌仍由用户停止驱动。其他工具保持既有期限。不新增超时设置UI、可调范围、默认10分钟或其他未批准建议。HTTP配置不改动，沿用现有ResponseHeadersRead行为。
