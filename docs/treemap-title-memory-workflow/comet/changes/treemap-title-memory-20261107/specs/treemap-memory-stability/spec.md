# 矩形图标题与运行内存稳定性

## 行为目标
目录标题在任意支持的缩放和平移下各自保持可辨识的区域边界；标题文字不越出本标题条。文件颜色、选择、导航及删除标记的既有语义保持不变。

应用在持续使用时仅保留当前展示、有限有效缓存及活动分析/清理所需的数据。旧视图、旧扫描、失效任务与绘制资源不得因无必要引用无限累积。活动证据不能被静默驱逐，授权行为不变。

## 验收
A1：1x 至 8x，多层目录，四向平移、视口边缘及不同 DPI，标题边界清晰且文字不跨条，交互不回退。
A2：同负载复现并记录内存与保留对象，针对证实的根因修复；预热后的重复绘制、扫描与导航不产生无用长期累积。
A3：失败回归变绿、相关既有测试通过，并由独立只读 Verifier 核对所有条目。
A4：完整双文件夹发布包保留运行时、DLL 与 skills，实际 EXE 清单符合测试 asInvoker、用户 requireAdministrator；真实发布环境验证源码编译与授权执行。
A5：非提权测试进程通过 cua-driver/cua UI 验证，仅截取应用窗口，并如实区分交付包清单验收与未执行的提权后 UI 验收。

## 边界
不改变扫描范围、清理权限与产品布局设计。不强制周期 GC，不新增通用资源框架。不带入其他会话未提交修改，不清理他人产物，不自动合并、推送或外部发布。

## 用户追加修复（2026-11-07 已明确要求）
A6：当前扫描推荐和随后无头扫描推荐合并后，原推荐仍绑定其真实扫描证据；没有目录变化时可以正常进入具体清理确认并执行。保留隐私、白名单、链接、保护路径、目录指纹及批准后复核；失效项返回准确原因，不统一误报。
A7：删除失败、已手动删除或推荐失效时，用户可安全移除单项及清空推荐列表；该操作只清空建议和释放该清单的证据引用，不删除任何文件。不自动清空活动分析或用户未请求的清单。
范围补充：修改现有推荐发布、共享清理校验、RecommendationsViewModel 与 RecommendationsPanel；新增相关回归测试及验收夹具，不新建通用框架或额外状态横条。

## 已确认标题边界与目录共边
- A8：临时顶部保持可见标题不得与固定子标题的完整区域相交；允许共边及浮点舍入，不再豁免上下各2像素。没有完整空位时临时祖先让位，不挤压文件、不移动固定子标题。展开folder的内容矩形复用子块侧边与底边，不逐层内缩或重复画完整框；仅标题条保留边界，折叠内容块、真实选择、悬停、删除标记仍保持可见。
