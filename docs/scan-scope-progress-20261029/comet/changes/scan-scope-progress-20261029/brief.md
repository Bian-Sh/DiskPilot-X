# 目标
修复子目录扫描先读取整盘 MFT 导致的慢扫描及进度误导，确保用户选择的扫描范围与界面计数一致。

# 范围
- 子目录首次扫描走目标目录遍历；整盘继续使用 MFT；保留同一路径后续 USN 增量扫描。
- 为进度区分整盘索引读取与目标范围计数，普通入口和无头入口一致。
- 保持已有文件夹计数包含目标根目录的口径，不引入无关清理或设置变更。
- 回归测试、非提权 UI 验收、发布目录源码规则验证，交付完整测试包与管理员包。

## 目录结构
### 新建
扫描范围与进度回归测试、共享进度格式化代码（如有必要）、本任务设计和验收记录。
### 修改
扫描路线选择、MFT 进度与目标计数传递、扫描进度本地化显示。
### 删除
无。
### 明确不建
不增加用户配置开关、扫描引擎抽象层、路径阈值策略或全盘索引缓存。

# 非目标
不修改其他会话代码，不合并、不推送；不读取文件内容或执行清理；不改变最终文件夹计数约定。

# 验收示例
- A1 子目录首次扫描（包括带尾分隔符）只进入目录遍历，不尝试 MFT、不产生虚假 MFT 失败原因；实际数量及大小一致。
- A2 卷根识别正确，整盘 MFT 和同路径 USN 增量分支保持可用；支持权限不足时真实回退及取消。
- A3 整盘索引进度明确标注卷与索引记录数，不作为目标目录计数；构树/大小统计使用目标子树计数；简体、繁体、英文与无头入口一致。
- A4 单元回归通过，并使用非提权测试包 UI 扫描原始目标，得到 447 个文件、15 个文件夹（含根目录）、282794037 字节；不读取整盘 MFT。
- A5 测试与管理员包均完整文件夹发布、包含运行时 DLL 和 skills；实际清单分别 asInvoker/requireAdministrator；真实发布目录中验证源码规则编译、授权的只读执行及失败诊断。记录真实源码来源，不宣称未做的提权后 UI 验收。
