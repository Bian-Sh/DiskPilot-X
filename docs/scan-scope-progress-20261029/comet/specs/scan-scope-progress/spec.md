# 扫描范围与进度

## 目标
扫描仅返回用户目标范围的实际文件树；进度必须说明统计范围，不能把整盘索引处理量显示成目标目录文件量。

## 行为
- 首次扫描子目录时直接遍历该目录；完整卷根扫描保留 MFT 快速路线，不能访问时按现有规则回退。
- 同一路径的后续扫描保留 USN 增量能力；权限不足不虚称成功，取消不产生完成结果。
- 索引进度标注卷根与索引记录数；目标文件统计与其分开，构树后仅使用目标子树计数。
- 保持目录数含目标根目录的既有口径；简体、繁体、英文和无头入口一致。

## 验收标准
- AC1：子目录首次扫描（包括带尾分隔符）只进入目录遍历，不尝试 MFT、不产生虚假 MFT 失败原因；文件数、目录数和大小与实际目标一致。
- AC2：卷根识别正确，整盘 MFT 和同路径 USN 增量分支保持可用；权限不足真实回退，取消不会宣称完成。
- AC3：整盘索引进度明确标注卷与索引记录数，不作为目标目录计数；构树/大小统计使用目标子树计数；简体、繁体、英文与无头入口一致。
- AC4：相关回归测试通过；非提权测试包 UI 扫描原始目录得到 447 文件、15 目录（含根）和 282794037 字节，不枚举整盘 MFT。
- AC5：测试与管理员包是保留运行时 DLL 和 skills 的完整文件夹，实际清单为 asInvoker/requireAdministrator；发布目录中验证规则源码编译、授权只读执行与失败诊断；记录源码来源，未经实际测试不宣称提权后 UI 通过。
