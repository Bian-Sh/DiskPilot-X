# 模型思考等级配置整合

## 未进入 main 的原因
原实现位于 thinking-capability-flags 工作树的未提交修改，核心新增文件未被 Git 跟踪；原 design.md 明确将 Git 提交或推送列为非目标。integration.json 记录的是工作区文件整合，不代表已提交或已合并。main 的 f385e24 是思考显示与超时改进，不包含模型能力配置。

## 功能链与约定
- 设置页每个模型行悬停显示笔形编辑按钮，点击打开锚定该行的思考配置菜单。
- ThinkingCapabilities 按接口格式、端点地址、模型名称构造 SHA-256 配置键；支持档位、选中等级与 Anthropic 控制方式独立保存。
- 设置页声明可选档位，聊天选择器只展示声明集合；切换模型恢复各自配置，稀疏集合不能使用枚举数值作为滑条索引。
- 默认档省略控制字段，关闭档显式禁用；OpenAI Chat Completions 与 Responses 使用各自字段，Anthropic 明确区分预算预设与原生 effort，不按模型名称猜测能力。
- 保留旧枚举数值与旧设置兼容迁移，不增加依赖，不纳入 Skill、清理规则和其他 UI 会话的修改。

## 整合方式
以 main 的 632a5f9 为基础建立隔离工作树，逐文件提取未提交功能，只选取思考相关资源键与滑条差异。通过独立索引补丁提交到 main，保留主工作区其余未提交修改，不使用自动 stash 或覆盖工作区。
