# 磁盘协作 Copilot 规格

## 目标与产品边界

SpaceMonger Copilot 的主工作区继续承担磁盘浏览与分析，右侧 Copilot 通过真实工具调用与它协作。用户可混合使用手动操作与自然语言任务，两者读取相同状态并更新相同结果。AI 负责基于证据推进行动，确定性的本地服务负责执行、保护与结果校验。

## 需求来源覆盖

| 来源 | 目的 | 对应验收 |
| --- | --- | --- |
| 用户要求使用指定 LoomX.Harness 替代旧 AI 逻辑 | 统一运行时与连续工具闭环 | A2、A3、A4、A6、A8 |
| 用户要求 UI 向 LoomX 靠拢 | 消息过程、输入区及视觉语言收敛 | A3、A11 |
| 用户明确否定对话成为默认主界面 | 保留磁盘工作区入口 | A1 |
| 用户明确同意磁盘能力可由 AI 调用 | 扫描、查询、视图、建议和执行闭环 | A4、A5、A6、A7 |
| 用户明确继续使用右侧 AI 面板 | 保持面板位置和主次关系 | A1、A11 |
| 全局工程约束和现有保护代码 | 本地保护、中文、验证、发布及产物隔离 | A7、A9、A10、A12 |

## 能力与场景

### Scenario: 磁盘工作区保持主入口
验收：A1

当用户启动应用时，磁盘路径、扫描和可视化仍是主工作区，Copilot 位于可开合和调宽的右侧。未配置模型时仍可使用手动磁盘能力。

### Scenario: 独立构建并实际运行 Harness
验收：A2

在仅存在本仓库源码的环境中，构建、测试与发布成功；Harness 来自有来源记录的仓库内快照；正式入口不使用旧文本 JSON 工具识别或第二套 Agent 循环。

### Scenario: 按真实顺序展示流式事件
验收：A3

模型首段正文到达后，在请求仍进行时即可读取；后续过程、工具调用、工具结果与正文遵循实际事件顺序。文本中的 JSON、Markdown 代码块和工具名称本身不触发工具执行。

### Scenario: 无扫描上下文也能完成扫描与分析
验收：A4

用户提出路径扫描/分析任务后，Agent 能解析允许的路径、执行扫描、等待真实完成并查询新的结果。扫描失败、取消或访问限制返回结构化结果，不生成虚假的扫描结论。

### Scenario: 视图和当前选择形成共享上下文
验收：A5

Agent 可读取当前目录、选择项和推荐项；定位已扫描路径与切换 Treemap/文件树后，界面和后续工具读取一致。未扫描、被排除或不存在的路径返回明确结果，不静默扩大范围。

### Scenario: 推荐生成使用统一执行与发布能力
验收：A6

手动分析和对话分析共用 Harness 与推荐发布工具。模型提出候选，本地应用范围、白名单和路径保护后发布到现有列表，并向同一轮 Agent 返回实际接受/拒绝的摘要。分析工具不得递归调用自身或另一个 Agent。

### Scenario: 批准绑定具体清单并回传真实执行结果
验收：A7

用户可在执行前看到目标项、总量和删除方式；拒绝即结束本次删除调用。批准后只执行匹配的清单；目标或方式发生变化则批准失效。执行结果返回成功、失败、跳过和实际释放量，界面与 Agent 使用同一结果。

### Scenario: 停止与故障后可继续交谈
验收：A8

停止终止活动网络请求、可取消扫描及批准等待，不开始后续工具。工具执行中断已产生的结果如实保留。下一条消息可正常继续；失效任务的回调不修改新的会话或扫描结果。

### Scenario: 配置有效且错误可理解
验收：A9

用户现有加密 Key、Base URL、聊天/分析模型、思考和语言设置在迁移后有效；请求实际采用对应模型。鉴权、限流、超时和服务端失败均可理解、可恢复；日志与错误详情不包含凭据或原始正文。

### Scenario: 本地保护独立于模型输出
验收：A10

模型无法通过伪造路径、建议标识、过期会话上下文或参数跳过本地保护。扫描、推荐与 AI 对话的白名单维持各自现有语义，清理前重新验证。

### Scenario: 右侧面板与 LoomX 交互语言一致
验收：A11

消息以正文阅读为主；过程按时间就地折叠，工具详情可展开；输入卡整合上下文、技能、模型信息与发送/停止。宽度 300、360、520 像素及明暗主题下内容不遮挡，用户上翻时不会被强制拉回底部。

### Scenario: 可验证的 Windows 交付
验收：A12

在完成自动化回归后，使用实际发布包验证扫描、视图联动、推荐、停止和确认清理。发布目录位于 outputs 并含可读上海时间；GUI 证据仅包含应用窗口；真实模型未验证的部分必须明确标注。

## 运行与保护约束

- 单会话连续循环；修改磁盘工作区状态的工具与手动操作共用并发策略。
- 普通查询、导航和已授权扫描分析连续执行；必要输入与高影响操作才等待用户。
- 工具结果包含可判断成功与失败的结构化数据；异常不能被包装成成功。
- 发布推荐只处理扫描范围内且本地通过保护的候选；模型声称安全不构成删除授权。
- 保留当前应用的技能目录与本地化资源机制，内部技术协议不得成为普通用户必须学习的操作步骤。
- 本次不提供通用任意命令执行、后台清理、多会话管理和 LoomX 网关产品迁移。
