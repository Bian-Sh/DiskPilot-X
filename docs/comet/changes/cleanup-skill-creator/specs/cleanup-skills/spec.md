# 清理技能与助手交互

# 范围

- 创建器、规则与资料持久化、校验和只读预览，兼容内置 Unity Skill。
- 受约束 XAML 面板与可选可信 C# 源码，编译器随产品发布；清理复用宿主确认链路。
- 空态引导一键发起对话，可滚动展示可用规则，保存后立即刷新目录。
- 移植 Loom-X askuser 的结构化问题、单选、多选、文本、数字、校验和取消体验，适配 WPF。
- 自动化回归、应用窗口 GUI 验收与 outputs 时间目录自包含发布。

## 目录结构

### 新建

- src/SpaceMonger.Core/Services/Skills/、Models/UserDecision.cs：Skill 包、资料、源码执行与问题契约。
- src/SpaceMonger.App/Views/AskUserCard.xaml、SkillTaskWindow.cs 及相关 ViewModel：任务交互。
- skills/skill-creator/SKILL.md：内置创作能力。
- tests 下相关规则、问题和动态 UI 测试。

### 修改

- Skill 存储/路由、工具注册、ChatViewModel、ChatPanel、MainWindow.Copilot、DI 和发布配置。

### 删除

无预定删除。

### 明确不建

不引入 Python，不改成 Avalonia，不提供通用 Shell 或不可信源码安全沙箱，不自动删除用户数据。

# 非目标

不重做磁盘主视图，不修改 Loom-X 原仓库，不提交、推送、合并或清理其他会话产物。

# 验收示例

- AC1：聊天空态出现创建规则与查看规则入口；已有规则可滚动并可一键发起对话，正常消息出现后隐藏空态。
- AC2：Creator 可创建/更新用户技能并立即在 @ 和规则入口看到，内置技能不可修改或遮盖。
- AC3：文本和公开网址可成为有来源的参考资料；无效、过大或受限输入明确失败。
- AC4：结构化清理规则可验证、只读试扫和展示本机候选；不把资料或猜测当成真实扫描结果。
- AC5：受约束 XAML 可打开面板、交互和重开；拒绝任意 CLR 类型、事件代码和不允许的绑定；仅提交候选，不直接删除。
- AC6：可选 C# 可在无 SDK/Python 环境下编译执行并返回诊断；执行前确认可信源码，明确不构成安全沙箱。
- AC7：askuser 支持结构化单选、多选、文本、数字、必填校验、其他答案与取消，答案回到同一模型任务，停止时释放等待。
- AC8：清理仍经过宿主当前清单版本、保护范围与最终确认；取消不执行。
- AC9：相关自动化测试通过，应用窗口验收有记录，并生成 outputs/上海时间命名的自包含发布包。
