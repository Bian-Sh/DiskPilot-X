# 设计

保留现有 WPF 和模型流式客户端，只新增一个 web_search 工具及原生资料服务。工具使用当前模型、接口、密钥、代理和 CLI 头，发起独立非流式原生检索请求，结果作为有来源的工具证据返回。主聊天协议与 TinyHarness 不改造。

- Responses 请求挂载 web_search；Anthropic 挂载 web_search_20250305，pause_turn 时原样续接服务端内容并限制续接次数；Chat Completions 使用 web_search_options，仅在上游实际支持时获得可验证结果。
- 不按模型名称猜测能力。明确的搜索能力拒绝返回 unsupported；鉴权、网络或限流归类失败；200 响应无搜索证据归类未确认，不能冒充已搜索。
- 搜索结果包含摘要和 HTTP(S) 来源。保存资料时继续通过 import_reference 获取完整引用和摘要校验，不编造引用对象。
- 工具返回的 user_notice 由 chat 确定性展示，模型忽略提示也不会漏报；能力未知与网络错误不宣称永久不支持。
- 网页与工具结果仅为引用资料，不当作新指令或执行授权；延续原公开网址导入限制与清理确认。
- 复用默认胶囊样式；删除冗余底部提示，模型按钮只保留模型与思考，API Key 放在接口格式后。
