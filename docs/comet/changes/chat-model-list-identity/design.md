# 设计

沿用现有 WPF、ModelCatalogService 与 CliIdentityService，保持改动集中。

- 空态独立按钮样式设常驻背景，延续 10px 圆角和 2px 纵向内边距。
- chat 展示仅认可候选缓存内已选模型，运行中仍显示实际使用模型；默认推断只保留在现有请求兼容路径。
- 设置用只读列表展示候选，模型选择统一留在 chat；自定义完整 URL 独立持久化，留空由原协议生成。
- CLI 选项附版本、完整头提示、逐项异步刷新；通过现有 SettingsChanged 联动 chat。版本缓存只存无敏感信息的版本号。
- 手动刷新绕过原后台仅一次限制，网络失败不清空当前指纹。Grok 暂无远程源，明确保留内置版本。
- 核心版本缓存发出变化通知；chat 与设置页通过 Dispatcher 同步身份标签、选项与指纹提示，覆盖首次请求的后台刷新。
