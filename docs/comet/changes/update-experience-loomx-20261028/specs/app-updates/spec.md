# 应用更新

## 目的
让用户从标题栏预览更新日志并下载更新，在设置页统一管理更新与历史。

## 行为要求
### 入口与预览
发现可用版本后在右上角显示更新入口；显示下载、进度、待安装与可重试状态。预览宽度约 380、最大高度 420，并受可用窗口约束；正文独立滚动。预览不采用 MouseLeave 自动关闭；仅在指针进入弹窗外其他可交互 UI 时隐藏。窗口关闭时释放预览。
### 设置更新页
沿用应用现有设置导航和主题，内容对齐 Loom-X。保存自动检查和更新代理偏好；关闭自动检查仍能手动检查；手动检查刷新服务器而非重复当日缓存。代理复用已有配置。历史左列版本、日期与当前/最新标记，右列完整日志与版本链接，分页加载、空态、忙碌和失败重试可见。
### 一致性与安全
标题栏、设置、关于共用同一更新状态。关于只展示状态。安装由用户主动点击，失败可见且不退出。下载取消或失败不得将不完整安装包标记为完成。
### 发布验证
按照主仓库 AGENTS.md 输出独立非提权测试包和自动请求提权的用户交付文件夹包；保持运行时程序集与 skills，验证清单、UI、源码规则编译和授权只读执行。
