# 目标
让 AI 依据实时容量分批扫描、分析和追加推荐；聊天以紧凑列表呈现待扫描和扫描状态；恢复后明确失效；修复推荐发布阻塞，并将编排契约写入宿主 skill。
# 范围
保留本聊天主目录已有修复，以 main 的 dad4765 为基础，在独立工作树整合无头扫描工作树所需实现。两处来源工作区保持不变。2026-11-02 用户明确同意完整方案和整合方式。

# 非目标
不合并 main、不提交或推送、不接管另外两项活动任务、不修改用户配置、不自动执行清理。
# 验收示例
- 超过单次路径上限时明确拒绝而非静默截断；回执披露实时快照预算和占用，skill 指导串行分批、等待回执以及容量不足时停止。
- 多批扫描证据可用于追加推荐；重复或父子重叠安全去重，保留旧勾选，失败不覆盖已有清单。
- 扫描按轮次形成紧凑列表，待扫描与真实进度可见，列表自然高度且最大240 DIP，超出内部滚动。
- 恢复后按实例、进程标识、当前路径和隐私策略复核；失效项保留说明但无Treemap入口，不自动重扫或恢复清理授权。
- 大批推荐校验不阻塞UI，提交有背压并复核来源和策略版本，避免逐项全表刷新，保留安全校验及现有交互。
- 三个宿主skill和工具说明一致，指导扫描、证据分析、首批建立后续追加、回执重试和部分完成，不误报整轮成功。
- 前序Treemap无限项、气泡状态和独立计时、空态自定义且不挤压视口、Token胶囊等回归通过。
- 完整文件夹测试包和交付包放入主仓库outputs；实际清单分别asInvoker与requireAdministrator，测试包UI及发布环境源码规则验证有证据。
