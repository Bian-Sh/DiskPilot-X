# 目标

减少发送给模型的工具结果中的重复信息，尤其是文件列表里反复出现的绝对路径；保持路径可准确还原、异常可见和后续调用可靠。

# 范围

1. 统一精简 find_by_name、find_by_path、list_children、summarize_subtree、find_large_files 的结果。列表仅声明一次基准绝对路径，条目使用相对路径，省去重复的 name、extension。
2. 默认保留相对路径、类型、精确 size_bytes；目录保留 child_count。last_modified 等详情按 details 参数请求；异常标志只在为 true 时返回。单项详情查询可获取完整元数据。
3. 默认保留结构化 JSON，提供可选 format=tree，合并搜索结果中重复的目录前缀，折叠只有一个后继的目录链，保证路径无损恢复；不使用省略号替代真实路径段。list_children 默认仍只查询直接子项，不自动递归扫描。
4. 路径基准随结果返回，不依赖上一次调用或当前工作目录；模型通过基准和相对路径构造后续绝对路径。若增加相对路径输入，必须显式传入 base_path，并在白名单检查前完成解析。
5. 明确结果上限和 truncated 状态，保留查询排序及安全相关信息。检查上下文、分析证据、推荐、技能、注册表等其他工具，针对已确认冗余实施局部精简，不对任意 JSON 做递归删字段。
6. 验证工具到模型的真实序列化输出，重新发布独立运行包到带可读时间的 outputs 子目录，使用应用窗口进行运行验收。

## 目录结构

### 新建

- 本需求的设计说明和针对精简工具结果的回归测试。

### 修改

- src/SpaceMonger.Core/Services/Agent/FileTreeAgentTools.cs：输出投影和工具参数说明。
- src/SpaceMonger.Core/Services/Assistant/DiskAssistantService.cs：工具调用契约和必要的投影适配。
- 受影响的测试、工具使用说明；其他工具仅在查明冗余后按需调整。

### 删除

无。

### 明确不建

不新增依赖，不做通用有损压缩框架，不修改文件系统扫描模型，不把完整路径从内部数据或真实操作参数中删除。

# 非目标

不改变扫描、导航、清理授权和白名单语义；不截断文件名或目录名；不触碰其他会话的产物。

# 验收示例

- list_children 的子项不含重复绝对路径和 name/extension，基准与子项可还原真实路径。
- 深层搜索结果的 tree 输出共享父目录，单子目录链可折叠；同名文件仍可区分，大小排序可追溯。
- 默认结果不输出全 false 的 flags，异常标志仍可见，详情可按需获取。
- 空结果、截断、中文路径、UNC、盘符根目录、白名单和越界基准均有明确行为。
- 对固定的长路径样例比较实际发送 JSON 的长度，记录减少比例；没有真实 tokenizer 时不把字符比例冒充 token 比例。
- 测试通过，独立运行包可启动，工具卡片能正常展示精简结果。
