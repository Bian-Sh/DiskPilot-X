# 工具结果精简契约

## 需求：共享路径基准

文件列表必须只声明一次完整基准路径；每个文件条目必须使用相对于该基准的无损路径。不得通过省略真实路径段、猜测工作目录或引用上次结果来还原路径。

### 场景：列出直接子项

给定一个已扫描目录，当调用 list_children，结果中的子项路径为直接子项名称；顶层 path 保留查询目录的规范绝对路径，path_format 标记为 relative。

## 需求：按需返回元数据

默认列表返回定位、类型、精确字节数和必要的目录数量，异常标志必须保留。重复名称、可从路径推导的扩展名和正常状态下的 false 标志不得逐项输出。调用方可显式获取详情。

## 需求：深层目录紧凑表示

目录树格式必须合并共同前缀，并可无损折叠单子目录链；不得将未命中父目录误当搜索命中或破坏结果大小排序语义。默认 JSON 格式仍提供结构化条目。

## 需求：有界结果与完整安全信息

达到输出上限时必须明确报告截断，不得让模型将部分列表误认为全部结果。路径白名单、错误、操作结果和清理风险字段不得因精简而隐藏。

## 需求：全链路兼容

精简结果必须可被聊天界面展示并用于模型后续调用。工具参数、返回值说明和测试必须与新契约一致。所有压缩效果必须按实际模型输入衡量。
