# 目标
落实 chat 空态、模型设置与扫描规则资料交互调整，模型能力以实际配置接口结果为准。

# 范围
紧凑常驻胶囊、模型缓存展示、模型列表与获取 URL、CLI 身份及刷新；按后续要求调整设置顺序及按钮内容；新增扫描规则入口支持用户提供链接和原生 Web 搜索，不支持时明确告知。

## 目录结构
### 新建
- 原生搜索资料服务和针对请求、来源、降级、通知的回归测试。
### 修改
- ChatPanel、ChatViewModel、ApiSettingsSection、SettingsViewModel、AiOptions、本地化资源。
- 模型目录/身份服务、DiskAssistantService 工具注册、应用 DI 与 skill-creator 指导。
### 删除
- 空态末尾的“先检查、再选择；清理前会请你确认。”提示。
### 明确不建
不修改 Loom-X，不增加依赖，不清理其他会话文件，不提交 Git，不引入第三方搜索 Key。

# 非目标
不替换用户已选模型，不重写已有流式协议客户端，不让网页资料变成执行授权，不改变扫描/清理确认链路。

# 验收示例
- AC1：空态问题默认有紧凑背景、半圆两端和可辨悬停。
- AC2：模型缓存为空或原选择失效时提示选择模型，真实候选可选并持久化。
- AC3：模型列表使用刷新图标和 ToolTip；完整获取 URL 可保存，留空沿用默认路径，复用凭据和代理。
- AC4：设置仅管理模型列表，无独立对话模型输入；API Key 位于接口格式之后。
- AC5：CLI 菜单逐项刷新可重复，失败保留旧值；Grok 明确采用与 Loom-X 一致的内置指纹。
- AC6：设置显示身份与版本、后台/手动刷新后与请求头同步；chat 模型按钮只显示模型名与思考等级，无 CLI 和末尾标记。
- AC7：相关回归、GUI 验收通过，outputs 生成上海时间命名的自包含包，保留其他会话产物。
- AC8：入口和无障碍名称为“新增一个新的扫描规则”，引导可提供链接/粘贴资料，旧入口文案及冗余末尾提示均删除。
- AC9：通过当前模型和已配置接口的原生搜索读取公开网络资料，保留实际来源；明确不支持时在界面直接提示，仍可使用已有公开链接导入。不把鉴权、限流、联网失败或缺少搜索证据一概说成模型不支持。
- AC10：覆盖各协议请求、真实来源提取、暂停续接、不支持/鉴权/空结果、取消和 UI 提示；普通流式聊天与既有引用导入保持可用。
