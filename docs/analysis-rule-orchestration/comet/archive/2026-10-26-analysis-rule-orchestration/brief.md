# 目标

保留“分析”按钮，把当前范围清理评估变成有明确目标、可动态发现规则、可按需询问并能给出真实结论的任务。用户无需输入清理关键词或选择固定 skill；规则是知识与快捷入口，缺失规则不导致分析失效。再以轻量且可控的方式提供偏好与重复需求建议。

# 范围

第一阶段完成分析入口语义、动态只读规则目录、适用线索核实、阶段内容与安全约束读取、必要用户参与、候选过滤与真实状态、扫描来源和最小历史恢复。第二阶段完成用户确认偏好、默认关闭的行为线索、克制的快捷入口建议。两阶段都属于本变更，不得以只完成第一阶段宣称整体完成。

本变更只消费既有规则读取与预览能力。用户明确指出规则创建模块应支持 CRUD，但另一会话正在重构，本次不实现、不重构其 CRUD、编辑器、存储格式、源码执行或面板。创建规则选项只允许交接既有入口；缺能力时如实降级，不自行补造创建模块。

# 验收示例

- 分析入口独立于关键词：已有扫描时点击分析，不输入清理关键词或 @技能，也能启动当前范围评估；重复点击不重入，不触发删除。缺少扫描时不编造结果。

- 新规则可被下一次分析发现：首次分析之后通过既有模块保存新规则，第二次分析发现它；单条损坏规则不会隐藏其他规则，相关版本变化不会错误复用旧结论。

- 适用线索不等于可删除：目录名与后缀相同的构建产物和运行组件，经内容及排除条件核实得到不同判断；无元数据的旧规则有兼容路径。

- 按阶段读取但不遗漏保护：多阶段与旧版 Markdown 两类规则均可评估；分析读取相关内容及必要清理约束，缺失或截断阶段如实说明。

- 无规则与网络不可用时的通用评估：没有专用规则仍能基于本地证据给出建议或明确无建议；网络失败不伪造已检索，私密文件信息不进入公开检索。

- 用户参与及外部创建交接：重要未知内容触发询问；用户可通用检查、补充、跳过、取消或转入已有创建入口。创建入口缺失时可返回，未评估部分不丢失；拒绝后不循环询问。

- 分析无法越权修改规则：分析能发现、读取及受限预览规则并询问用户；直接或通过伪造参数请求保存、更新、删除、源码运行和清理均被宿主拒绝。

- 被过滤不被说成没有可清理内容：提供均被硬保护或白名单过滤的候选，得到可理解的原因；AI 不重复试发相同受限候选，不展示内部发布术语作为主要结论；真正无候选时有明确总结。

- 完整、部分、失败和取消清楚区分：分别验证有推荐、完整无推荐、重要部分跳过、工具失败和取消；聊天与列表状态一致，不以空列表伪装全部完成。

- 来源正确且不覆盖当前意图：手动、聊天和规则入口扫描分别保存来源；取消不修改旧扫描。旧扫描原为统计空间，新点击分析后按当前清理评估目标进行。

- 历史读取最小化：同会话上下文缺失时用任务摘要恢复；新会话先读摘要，未获许可不得读原文。历史删除或隐私限制后不通过摘要绕回；旧清理确认不被继承。

- 分析来源可复核：结果能说明使用了哪个扫描、范围、规则版本和用户补充；读取失败、未执行和通用推断有真实标记，不虚报覆盖率。

- 偏好可控且不是权限：用户确认的范围偏好可保存、读取、更正、删除或停用；临时回答不被保存，偏好不能放宽保护或替代删除确认。

- 行为统计是可选的最小记录：未启用时不积累；启用后查询、分析和清理分开，失败取消不记成功。关闭后停止，清除后不再影响判断，记录不含私密原文。

- 快捷入口建议克制且可拒绝：足够重复的成功关注可引出一次建议，用户拒绝后遵守冷却或不再提醒；接受仅转交既有创建流程，不自动创建或删除。

- 询问等待期间发生变化：等待用户或发布期间更换扫描、规则、隐私限制或偏好，对受影响判断重新核对；旧结果不能覆盖新范围，取消和规则内容不能绕过权限。

- 旧数据与并行模块兼容：旧规则、扫描和会话无迁移即可读；缺失信息按未知处理。对本次 diff 进行路径检查，规则创建模块、其正式规格和既有用户规则零改动。

- 可复核的最终交付：两阶段测试、独立验收、隔离后台 UI 证据及时间命名发布包均有真实记录；未实现或未执行项不记通过，普通回答不绑定固定句子。

# 约束与不变量

- 当前目标优先于旧扫描的任务意图。扫描来源与分析任务分开，取消不得污染旧扫描。
- 候选、接受、过滤、发布失败、完整无推荐和重要部分未知必须区分；不得用空数组推断没有可处理内容。
- 匹配不等于可删除。规则缺少阶段或适用字段时保守兼容，不编造能力；约束、保留条件和恢复代价不能省略。
- 跨会话先读最小摘要；原文访问需要有效授权，删除或隐私变化后不能经摘要绕回。
- 偏好只在用户确认后保存，可查看、更正、删除与停用；行为记录默认关闭，启用后只保存最小主题事件。
- 使用记录建议默认按近 30 天同主题同动作至少三次成功触发资格；30 天最多提示一次，暂时拒绝冷却 30 天，不再提醒持续到用户重新启用。阈值是防打扰默认值，不是固定模型台词。
- 所有应用改动需测试、独立验收、后台应用窗口验证和 outputs 内时间命名发布包；未执行不算通过。
