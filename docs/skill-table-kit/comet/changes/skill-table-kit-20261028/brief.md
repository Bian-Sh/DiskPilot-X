# 目标
把技能结果表格建设为宿主内置 UI 组件，修复用户截图中的圆角、标题横线、选择与列宽问题，供 skill-creator 创建技能时直接声明调用。

# 范围
沿用 SkillUiSpec 的 table 区块；替换等宽模板为共享表格组件，兼容 headers/cells，增加可选列配置。支持表头三态全选、每表反选、只选择可选行、汇总数量与容量。列支持自动、固定、比例、对齐与换行；统一主题、表头、悬停、选中及长文本提示。去掉标题横线，统一原生外壳与 WPF 圆角。

# 验收示例
- 旧 headers/cells 技能与新列配置均能显示；新配置解析有边界限制，skill-creator 文档与真实 API 一致。
- 三态全选、反选、单行选择相互同步，只影响当前表格可选行，数量容量回传正确；空表和不可选行安全。
- 盘符与版本紧凑、长详情获得更多宽度；表头行对齐、缩放无错位；长文支持省略提示或换行，主题状态统一。
- 标题横线移除，圆角外壳与内容一致，最大化不留圆角缺口；应用窗口实际截图验收。
- 定向和回归测试通过；独立 Verifier 检查每项要求。
- 在主仓库 outputs 下输出带时间的非提权测试包与提权用户交付包，检查实际 EXE 清单、文件夹 DLL/skills，并从发布目录验证源码编译与授权只读执行；UI 使用 cua-driver 验收，明确不把提权 UI 当作已验收。

- 浅色技能结果窗和任务窗无黑色角部残边/双重黑框；普通/最大化/还原及明暗主题切换正确，使用应用窗口截图对照。
- 聊天入口卡文字不在带Effect的祖先下，和正文使用一致的清晰文本渲染；阴影仅在背景层，保留可点击入口。
- 动态窗口视觉上仅一个主标题，标题栏保留拖动、最小化、最大化和关闭，系统Window.Title与无障碍名称仍在。
- 模型或技能声明bar_chart后聊天和完整窗口均绘制真实比例的条形；JSON/源码链路、零值/非法值安全；聊天仍不内联表格/海报。Steam盘点返回明确bar_chart并在技能契约说明真实字段。
- 打包源码已包含main已提交记录并保留本任务改动；回归、发布清单、源码编译执行和独立验收重新完成，禁止把旧包当新包。

- 用户确认的透明主题：已打开的技能结果窗与任务窗实时跟随全局透明开关、透明程度和明暗主题；只调整背景材质/底色，不降低整窗、文字、按钮或图表Opacity；表格不再被不透明底板遮挡，关闭透明或系统不支持时正确实色回退，并保留单一DWM圆角和无空白更新按钮。

- 主题配置新增后台保持通透选项，默认关闭并保存；只在磨砂启用时生效，开启后已打开的主窗/技能结果窗/任务窗失焦仍保留玻璃材质，不修改真实焦点/Window.IsActive、不抢前台。关闭选项后恢复系统失焦回退，切换主题预设和重启保留该选项，输入/勾选/圆角/窗口控制不回归。

- Steam完整弹窗按统计概览、游戏封面、明细表格、占用排行排序，封面优先，排行保留但不抢首屏；聊天仍按显式图表声明呈现。
- 宿主共享DataGrid滚轮支持条件转交：当前方向能滚时只滚内部，到边界或无可滚动内容时交给同窗口最近外层滚动容器；保留原生步长且不双滚、不影响横向滚动与选择，覆盖内置结果表与技能任务表，更新页既有规则不回归。
- 宿主统一内置bar_chart、pie_chart、donut_chart；JSON/源码和skill-creator使用同一声明契约，聊天与完整窗口复用同一图表组件。统一主题/透明底、图例与数值百分比提示；饼环只取有限正值并安全归一化，零/负/非有限/空数据有明确空态，单项全圆和极值可用，不自动插入图表、不新增大图表依赖。
- 三类共享图表具有轻量载入与悬停动效：CubicEase/EaseOut约400ms，条形从左展开，饼/环扇区按占比展开；约150ms悬停提亮，扇区轻微向外浮出且与图例联动，移出平滑复原。不对文字/整窗做缩放或降透明度，不改变最终比例、布局与选择。仅首次展示或Section数据更换播放载入，滚动/尺寸/主题/语言切换不重播；尊重Windows关闭动画设置，关闭时直接最终态并清理卸载动画。
