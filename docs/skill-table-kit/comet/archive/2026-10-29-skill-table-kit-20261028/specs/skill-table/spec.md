# 内置技能表格

## 需求：兼容且可声明的表格契约
宿主必须保留 headers/cells，允许 table_columns 声明列头、自动/固定/比例宽度、最小最大宽度、对齐和换行。最多六列，非法输入安全降级。skill-creator 文档与实际解析和源码 API 一致。
### 场景：旧技能与新技能
- 旧 headers/cells 在新组件中正常呈现，新 table_columns 经 JSON 与源码构造均能呈现；非法宽度、未知对齐及列数边界安全处理。

## 需求：按表格隔离的选择交互
宿主必须提供表头三态复选框和反选，只影响该表格中 Selectable=true 的条目；单行、批量、窗口汇总与回传保持同步。
### 场景：部分选择与批量操作
- 未选、部分选中、全选正确切换；从部分选中点击全选；反选不改变不可选行及其他表格。空表无可操作选择，数量与容量准确。

## 需求：统一且可伸缩的布局
宿主必须共享表头与行的列宽，默认压缩短内容列并把余量留给名称和详情，提供主题表头、悬停和选中态及完整文本提示。
### 场景：窄宽窗口与长表
- 长文本按配置换行或省略并提供完整提示；窄宽窗口列对齐，紧凑列不等宽平分，长表滚动可用。明暗主题动态生效。

## 需求：一致的技能窗口外壳
宿主必须移除标题上方蓝色装饰横线，窗口外壳与内容圆角采用一致轮廓，最大化无圆角缺口。
### 场景：普通与最大化窗口
- 普通窗口圆角与内容边缘一致，最大化为直角；只截取应用窗口进行实际 UI 验收。

## 需求：可验证交付
必须通过自动测试和独立验收，输出完整文件夹而非单文件或 ZIP。
### 场景：发布目录实测
- 主仓库 outputs 下两个带可读时间的包均为 SelfContained=true、PublishSingleFile=false、PublishTrimmed=false，保留 DLL 和 skills；测试包实际 EXE 清单 asInvoker，用户包 requireAdministrator；发布目录内源码校验及授权只读执行成功，失败诊断完整；非提权测试包使用 cua-driver 完成交互，不冒称提权 UI 已实测。

## 需求：干净且不重复的窗口标题与边缘
动态结果窗与任务窗必须避免透明底层泄漏形成黑色角边；只绘制一套主题轮廓。自绘标题栏不重复显示图标和名称，主标题上移，保留系统标题、窗口按钮与拖动。
### 场景：明暗主题与窗口状态切换
- 以真实应用窗口截图检查四角和边框；最大化/还原不残留黑框，任务窗与结果窗一致。

## 需求：锐利的聊天入口文字
入口卡文字不得作为阴影Effect的子树离屏合成，阴影仅作用背景；正文与卡片保持清晰文本排版，入口整卡和按钮仍可打开视图。
### 场景：正文与卡片并排比较
- 入口标题、摘要、统计文字可读且不模糊，主题切换保留清晰度。

## 需求：聊天内联真实条形图
允许Kind为BarChart的区块在聊天中直接展示；表格、海报、统计卡与长文本继续通过入口打开完整窗口。源码Provider和JSON工具均以显式bar_chart及真实metric驱动，不能把海报metric当作已生成图表。
### 场景：技能源码与模型渲染
- 两条路径的正数条形按最大值比例绘制；零值、负值和非有限数安全处理。Steam Provider明确返回占用图表。聊天只内联图表，完整窗口仍含全部区块。

## 需求：动态技能窗口完整继承透明主题
结果窗和任务窗必须实时继承全局透明材质开关、透明程度与明暗主题，且按各自窗口的材质启用结果选择透明或实色回退。仅背景层允许半透明，不降低整窗或前景控件的Opacity，不为每个skill增加独立配置。
### 场景：已打开窗口实时调整材质
- 开启透明后，结果窗与任务窗的背景能透出经过磨砂处理的环境，表格底板不阻挡材质；调节透明程度实时生效，不重建窗口或丢失输入/选择。关闭透明或材质不可用时使用实色背景，文字、按钮和图表仍保持可读；原生圆角和标题栏控制不回归。
## 需求：可配置后台保持通透
主题配置提供后台保持通透选项，默认关闭，持久化保存并在配色预设切换后保留。只有启用磨砂时选项生效，主窗口和技能动态窗口统一继承。
### 场景：失焦但保留玻璃材质
- 打开选项后，即使前台属于其他进程，目标窗口仍呈玻璃背景；真实Window.IsActive、输入焦点和前台窗口不变，不发送WM_ACTIVATE或调用SetForegroundWindow。关闭选项恢复系统默认失焦回退；关闭磨砂仍实色回退，重新打开磨砂可恢复此选项。输入、勾选、原生单一圆角及窗口按钮行为保持。
## 需求：Steam封面优先
完整弹窗按统计概览、封面网格、游戏表格、占用排行排序，所有数据仍来自真实只读盘点，图表作为最后的补充信息。
### 场景：默认游戏库展示
- 有封面时先展示游戏图片，再展示明细，排行最后。无封面仍保留原有占位；显式条形图仍可在聊天入口旁内联。

## 需求：宿主表格条件滚轮转交
宿主通用DataGrid必须在当前方向可以滚动时保持内部原生滚动；边界或无可滚内容时，把滚轮只交给同窗口最近外层ScrollViewer。通过主题默认接入而非Steam特例。
### 场景：长表、短表与边界
- 中段只滚表格，上边界向上/下边界向下只滚外层，反方向仍可回滚表格；短表/空表不吞事件，无外层不越窗；不引入双滚、不改变选择或水平滚动，更新页版本历史既有行为不回归。

## 需求：内置共享图表组件
宿主提供bar_chart、pie_chart、donut_chart三种声明式图表，复用同一控件渲染聊天与完整结果，不让技能自行绘制或注入XAML代码。兼容旧枚举数字与已有bar_chart契约。
### 场景：类别占比与安全降级
- 饼与环按有限正metric占总量的比例绘制，图例、数值和百分比提示清晰；环中心可显示合计。单项为完整圆/环，不出现缺口；极大有限值不使合计/角度溢出。全部无效或零值时显示本地化空态而非伪造比例。
- 同一声明在聊天与弹窗显示一致，图表继承明暗/透明主题并响应语言切换；窄宽不截断关键图例，图表不自动加入无声明结果。tool schema、源码API与skill-creator文档示例同步，不增加大型图表依赖。

## 需求：宿主图表轻量缓动
bar_chart、pie_chart、donut_chart共享宿主载入与hover动效，不增加技能JSON字段或第三方依赖。
### 场景：载入、联动与减少动画
- 首次Loaded及Section数据更换触发约400ms的CubicEase/EaseOut，条形仅数值条从左展开，饼/环只展开扇区；最终几何与比例准确，文字/图例不缩放、不降透明。
- 悬停数值条轻微提亮；悬停扇区或其图例时约150ms提亮并向外浮出约4 DIP，移出平滑复原；悬停不改变布局和数据，命中区域不跟随浮动而抖动。
- 同一数据的滚动、尺寸、主题、语言变化不得重新播放载入。快速换数据/进入离开hover应从当前状态接续，关闭或卸载控件应清除动画与订阅。Windows关闭客户区动画时直接显示最终状态，hover不播放缓动。
