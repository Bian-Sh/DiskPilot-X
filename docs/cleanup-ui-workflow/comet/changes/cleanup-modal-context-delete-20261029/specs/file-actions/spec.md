# 文件操作与清理确认

## 弹窗
弹窗固定居中，随内容按需增长且不超出宿主安全边距；正文独立纵向滚动，标题与操作常驻。推荐清理仅展示数量、大小、方式及必要警示，破坏性操作默认取消。

## 文件操作
Treemap 和文件树为同一文件系统入口。只有文件可调用默认程序打开；定位操作显示类型相关中文，英文 Show in Explorer，打开父目录并选中目标。删除需二次确认，使用设置指定的回收站或永久删除方式，执行前复核对象和授权快照，失败报告而不伪装成功。

## 扫描快照标记
成功删除后在当前扫描快照保留原节点和布局，Treemap 以红色边框标记，文件树以横贯行的红线标记。目录后代同步标记；与普通选中态独立；导航、排序与视图切换不得丢失。禁止重复打开或删除已标记对象。下次扫描开始清除，不自动重扫；统计及现有安全校验不得失真。

## 发布约束
独立工作树开发，主仓库 outputs 下交付完整自包含非裁剪文件夹，不提供单文件或 ZIP。测试包不提权，用户包内嵌管理员清单。用真实发布环境验证动态源码规则与应用交互，未实测部分不得声称通过。
