# 应用更新体验
## 更新入口与状态
应用在发现可用版本时于标题栏右上角展示更新入口。入口、设置页与关于页读取同一个更新状态，支持下载进度、错误提示、重试及安装就绪；安装仅由用户主动触发。
## 更新日志预览
悬停入口打开最大高度420的浮层，长日志由内部 ScrollViewer 滚动，正文、列表、代码上的真实滚轮输入也必须有效，不能只验证程序调用 PageDown。采用 Loom-X 的紧凑排版：正文13、行高19、标题按18/16/15/14/13分级，移除文档默认页边距，头部仅版本与发布日期并以细分隔线分隔。弹窗内不含任何按钮或下载状态；下载、进度、失败和安装就绪统一由右上角入口表达，待下载时仅显示图标，不在图标右侧显示版本号。移入浮层、滚动条及外部非交互空白保持显示；移入外部可交互控件隐藏；点击弹窗外任意位置也关闭，包括应用内非交互空白，不得吞掉原控件点击。关闭和窗口失活清理浮层。不使用离开计时关闭。
## 更新设置
设置提供更新分区，包含当前版本、自动检查开关、更新代理开关、手动检查与双栏发布历史。列表支持分页，选中版本显示日志和日期，可打开对应发布页。加载、无内容、网络失败与重试应可辨识；刷新失败保留已有历史。设置持久化。
## 关于状态
关于页更新区域只显示版本和更新状态，不执行检查、下载、取消或安装。原有其他关于信息与捐赠入口保留。
## 交付与回归
测试覆盖状态转换、下载错误恢复、分页重试和浮层关闭判定。保持三语界面。发布完整 self-contained 文件夹，保留运行时 DLL、宿主契约与 skills，测试包 asInvoker、用户包 requireAdministrator；对未执行的验证明确标注。
## 安装与步骤边界
第一步仅合入app更新模块。已下载并验证的安装包由用户点击右上角入口启动可见安装向导，启动失败或取消提权不退出应用。未准备时只下载，不在检查或启动时自动安装；第二步从合并后的main实现setup.exe安装包、tag构建、发布v1.0.0，并用低版本测试包检验真实更新。
