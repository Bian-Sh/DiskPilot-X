# 设置、导航与 Responses 修复规格

## 模型列表滚动
模型列表复用更新说明现有 NestedScrollWheel 路由：列表存在当前方向可滚空间时仅滚内部，否则交给同窗口外层设置页。保留原生步长及选择、排序和编辑交互；不向其他窗口转发。

## 面包屑身份
普通磁盘路径的目录身份不因尾部分隔符或大小写变化。为外部目录构造父链时，每一步必须向实际父目录推进，保留盘符根与合法目录名，不创建与当前目录规范化后同路径的父节点。已有扫描树导航优先使用真实节点。

## Responses 历史契约
本地历史序列化不得在保留 reasoning 项时丢弃其 summary。上游返回合法摘要数组时保留所有摘要项；确实没有摘要时输出空数组。保留 reasoning 身份、加密内容及原有工具回合关联，不通过删除思考历史绕过错误。不修改 Chat Completions 协议行为。测试应检查第二轮实际发送的 JSON，并覆盖多轮、空摘要和非空摘要。

## 思考等级同步
直接点击轨道、拖动及键盘操作都走一致的等级更新链路。等级文本由实际选择驱动，持久化和协议参数由同一选择生成；模型能力变化和程序刷新不得反向写入错误等级。默认仍为现有默认语义，而非擅自映射为某个具体思考等级。

## 验证与交付
四项行为以 brief 的 A1 至 A4 为准；回归与 UI、独立评估遵循 A5；真实文件夹环境源码技能编译和只读执行、双清单核验及完整目录交付遵循 A6。不把模拟中转站测试说成真实账号联调，不把清单检查说成提权 UI 已验收。

## API 验证直觉与安全诊断
验证链路只使用同配置最近一次刷新成功返回的真实模型候选；优先匹配当前聊天模型，否则以目录第一项仅作测试，不设置 ChatModelName 或改写该模型思考配置。先完成目录刷新再发生成验证；空目录或刷新失败不使用缓存或默认模型继续。任何 await 后配置已变化则放弃旧结果，验证期间模型选择变化也不得用旧选择覆盖新状态。
进度和结果显示所测模型；网络、模型、额度、协议参数失败不能显示成密钥鉴权失败。日志保留脱敏的状态码与上游摘要等结构化字段，不依赖 Exception.ToString 输出自定义属性；验证模型本身不可信，显示和日志均以纯文本、脱敏方式处理。行为覆盖 A7、A8，发布与经验传递覆盖 A9。
