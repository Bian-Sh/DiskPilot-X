# 清理确认与文件操作设计

## 决策
- 以原始关闭弹窗约386×180为默认外框比例，消息弹窗宽度在460与宿主边界内取值，最小高度按180/386同步增加；多内容可继续有界增高，最多700且不越出宿主。自定义内容弹窗不套用此规则。
- 标题单行固定约48 DIP（20 DIP字、24 DIP行高、上下12 DIP留白），按钮保持原尺寸及底部16 DIP锚点；不缩放固定区，新增高度留给正文。
- 正文在独占视口中垂直居中，上下间隙相同，左右28 DIP；内部上下安全留白各16。超过视口时按自身高度从顶部滚动，不为了居中隐藏开头。
- 标题居中、无图标、纯白字；关闭应用与清理确认共用20 DIP / SemiBold。常规标题固定中性深灰#62686E。
- 警告使用降低饱和度而非变浅粉化的素雅黄褐色，固定#86714F；高危采用用户从两张同布局预览中选定的第二种固定色#BB2124（187,33,36）；全主题一致，清理按钮原红#FF453A不变；全弹窗保持不透明，不增加玻璃或透明配置。
- 以实际布局快照及回归检查宽高关系、标题高度、按钮底边、正文上下gap，避免只调单个padding。
- 清理／右键删除统一使用连续 Inline 段落，名称、项目数、总量、方式半粗强调；单项只展示末级名称，多项不列明细；不重复数量和方式。文件名作为 Run 字面量，不解析 Markdown/XAML。
- 通用消息弹窗以 Auto / 星号 / Auto 三行布局固定标题与按钮，正文用 ScrollViewer；卡片保持居中，受最大 700 高及宿主四周 24 边距限制。
- 推荐清理手动确认仅呈现数量、总大小和方式；助手确认保留审核上下文。破坏性确认默认取消并实际聚焦取消按钮。
- 聚合虚拟块引用父目录而非独立文件集合，真实 Treemap 右键入口禁用其删除；普通文件／目录菜单不受影响。
- Shell 定位采用 SHParseDisplayName / SHOpenFolderAndSelectItems，文件与目录均定位父目录中的目标，避免直接创建 explorer.exe；仅文件提供默认程序打开。
- 删除期间所有设置入口暂时不可打开；设置变更递增授权版本，确认后及最后一次异步复核结束都核对会话、扫描、标记、方式与版本，变化即撤销旧批准。
- 删除执行复用 CleanupPlan 和 CleanupService。确认前采集快照，确认后复核扫描会话、设置模式、保护规则和目标指纹，执行服务再次核对指纹；不自动重扫。
- FileEntry.IsDeleted 是只在内存存在的可通知视觉标记。节点与 Size、类型配色保留扫描快照，状态栏会话总数扣减成功删除项；快照大小不等于当前磁盘实时值。
- DeletedEntryState 使用按扫描会话弱引用保存的去重集合计数，避免重复结果、父子目录重叠及清除视觉标记后重复扣减。
- Treemap 最后绘制红框，普通选择不会覆盖；TreeView 跨九列叠加红线。扫描开始清除缓存及当前树标记。

## 验收边界
- 独立配置及假数据目录，不使用真实用户文件做删除测试。
- cua-driver 后台读取和按钮操作；后台右键坐标受遮挡时用验收通道触发真实菜单事件，确认按钮仍由可见 UI 执行。不声称已验证被系统阻止的物理右键注入。
- 交付文件夹发布，自包含、非单文件、非裁剪。分别读取实际 EXE 清单，不将清单核验等同于管理员进程启动后的 UI 验收。
