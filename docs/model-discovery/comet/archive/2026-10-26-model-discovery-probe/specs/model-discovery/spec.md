# 智能模型目录发现

## 能力
用户在 AI 设置中先选择系统、直连或自定义代理，再刷新模型目录。模型发现基于所选协议、已知服务商和部署前缀，顺序尝试同源候选；自定义模型获取 URL 拥有最高优先级且不会被擅自替换。

## 成功与失败
仅含有效模型 ID 的响应可以更新模型列表。候选未命中时继续尝试，成功立即停止。鉴权、权限、限流和用户取消不是路径不存在，不盲目继续。探测次数、单次耗时、总耗时和读取字节均有限制。所有候选耗尽时弹窗提示填写完整列表 URL 后再试；任何失败不清空已有列表。

## 可观测性与安全
每次尝试、分类原因、响应摘要和最终异常同时进入应用控制台与本地滚动日志。凭据、敏感查询参数和代理密码不得进入日志或弹窗。自动发现不能跨源发送凭据或跟随不受控重定向。

## 界面
代理设置必须在模型列表之前，编辑值立即参与本次请求，无需重启或另行保存。失败弹窗使用现有应用内弹窗，不打开浏览器、不自动更改对话地址。
