# 目标
模型列表能够依据当前协议、服务商和中转部署前缀有序尝试常用同源候选，失败可诊断、可由用户提供地址继续恢复。

# 范围
支持 OpenAI Responses、Chat Completions、Anthropic Messages，区分常用国产/海外服务商预设与 New API/Sub2API 通用中转路径；不增加供应商强制选择步骤。代理设置在页面顺序和请求配置上均先于模型获取。候选耗尽后弹窗要求填写完整模型获取 URL 再试。

## 目录结构
### 新建
- src/DiskPilotX.Core/Services/Llm/ModelCatalogEndpoints.cs：生成有序、去重的模型目录候选和服务商提示。
- tests 中对应模型发现和日志回归用例；docs/model-discovery/design.md：设计与验证边界。
### 修改
- ModelCatalogService、ModelHttpClientFactory：有界探测、代理复用、日志和重定向安全。
- SettingsViewModel、ApiSettingsSection.xaml、MainWindow.ViewModels.cs 和本地化资源：代理顺序、失败摘要和应用内弹窗。
### 删除
不删除现有文件或其他任务产物。
### 明确不建
不新增日志系统、服务商管理器或动态模型猜测请求，不改写对话协议。

# 非目标
不自动改动主线，不提交、合并、推送或清理其他工作树；不遍历用户所有日志或使用截图中的密钥；不承诺未知站点一定提供模型列表。

# 约束与决定
用户已经确认完整方案，并追加确认候选耗尽弹窗、代理优先和独立 worktree 专用 Comet 产物目录。所有自动候选保持同源，不跨域转发密钥，不自动跟随重定向。手填 ModelsUrl 直接请求，不自动猜测该显式地址的其他路径。日志脱敏 API Key、代理密码、敏感 URL 参数及响应片段。

# 验收示例
- AC1：DeepSeek /anthropic 地址优先尝试官方目录；OpenAI 两种协议、Anthropic、国产/海外预设和带前缀中转均生成正确同源去重候选。
- AC2：404/405、HTML、无效 JSON、空列表继续尝试，首个有效目录即停止；完整模型 ID 去重排序，失败保留旧列表。
- AC3：鉴权拒绝、权限拒绝、限流、取消及时停止；单次/总体超时与响应大小有界，不跨域泄漏凭据。
- AC4：每次尝试及最终异常可在控制台和文件日志中检查，包含地址、状态/异常原因、耗时，敏感内容脱敏。
- AC5：代理控件位于模型列表之前，当前编辑中的代理主机/端口/账户/密码即时用于发现；非法自定义代理不悄悄直连。
- AC6：所有候选耗尽时出现应用内弹窗，告知填写模型获取 URL 后重试；显式 URL 优先并保留原列表。
- AC7：自动化测试通过，使用 cua-driver 对实际应用验收，并在 outputs 生成带可读时间的自包含发布包。
