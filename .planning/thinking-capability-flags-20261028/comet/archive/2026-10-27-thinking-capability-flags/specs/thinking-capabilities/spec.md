# 目标
按接口格式及模型配置思考等级能力 flags，并在对话弹窗中单选实际档位。用户已在聊天中确认本方案并授权实现。

# 范围
设置页在每个模型行右侧、删除按钮左侧提供悬停显示的笔形编辑按钮，点击后在该行下方弹出思考档位复选菜单，取消独立的页面底部能力编辑区；多选档位默认全选；按端点、协议和模型分别保存，切换模型时保留各自配置。OpenAI 两种格式使用各自 effort 字段；Anthropic 保留预算预设并允许用户明确选择原生 effort 控制，不按模型名称猜测。

## 目录结构
### 新建
- 核心思考能力合同、配置与回归测试。
### 修改
- AI 设置、对话滑条、模型请求及本地化资源。
### 删除
- 无。
### 明确不建
- 不进行计费探测，不增加模型名称推断表，不修改其他会话的改动。

# 非目标
不自动声称模型支持全部档位，不自动升级已有 Anthropic 预算模式，不进行 Git 提交或推送。

# 验收示例
- 每个模型行右侧在悬停或键盘聚焦时显示编辑图标，位于删除按钮左侧；点击在该行下方打开菜单，配置只绑定该模型。菜单展示与协议和控制方式对应的复选项，初始全部勾选；能力声明提示为手动配置、未验证。
- 对话滑条仅包含当前 flags 勾选的档位，稀疏档位顺序正确；当前档位被移除时回落到有效选项。
- 模型、端点和协议之间配置互不污染；旧版设置正确迁移，重启后恢复配置。
- 默认省略控制字段；关闭准确发送 none 或 disabled；minimal 原样发送，不静默改成 low。
- Anthropic 预算预设与原生 effort 分开标示，显式选择控制方式后正确发送对应字段。
- 核心与 WPF 测试通过，使用窗口级 GUI 验收并生成 outputs 下可读时间命名的发布包。
